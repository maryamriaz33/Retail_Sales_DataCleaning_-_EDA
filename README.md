# Retail Sales Data Cleaning & EDA

A Pandas-based data analysis project focused on cleaning, exploring, and transforming a messy retail sales dataset.

## 📌 Project Overview

This project demonstrates a practical data analysis workflow using Python and Pandas. The dataset contains real-world data quality issues such as missing values and duplicate records.

The main goal is to prepare the dataset for further analysis by identifying and handling data-quality problems, exploring the available data, and creating useful features.

## 🎯 Objectives

- Understand the structure of the retail sales dataset
- Identify missing values
- Detect and handle duplicate records
- Inspect data types and unique values
- Clean and transform columns
- Perform exploratory data analysis using Pandas
- Create new features for analysis
- Prepare a clean dataset for future visualization and advanced analysis

## 📊 Dataset

The dataset contains retail transaction information such as:

- Transaction ID
- Customer ID
- Category
- Item
- Price Per Unit
- Quantity
- Total Spent
- Other transaction-related attributes

## 🧹 Data Cleaning

The following data-cleaning tasks were performed:

- Checked dataset shape and structure
- Inspected data types
- Identified missing values
- Checked for duplicate records
- Handled missing and duplicate data
- Validated cleaned columns
- Checked unique and inconsistent values
- Converted data into appropriate formats where required

## 🔍 Exploratory Data Analysis

Exploratory analysis was performed using Pandas to understand:

- Category-wise sales
- Product performance
- Customer purchasing patterns
- Transaction values
- Quantity purchased
- Total spending
- Summary statistics
- Relationships between important numerical columns

## ⚙️ Feature Engineering

New features were created from the existing data to make the dataset more useful for analysis.

Examples include:

- Total Sales
- Transaction/Order Value
- Date-related features
- Customer-level spending metrics
- Other derived analytical features
